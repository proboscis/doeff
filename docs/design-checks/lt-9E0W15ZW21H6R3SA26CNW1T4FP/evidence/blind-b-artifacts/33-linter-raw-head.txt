
warning DOEFF172 - Dict Outside Its Place (70 occurrences)
────────────────────────────────────────────────────────────────────────────────
  What: 写像は cache のためだけに効果の層(defhandler)が持つ — handler の外の defk・deff・defn の本体で写像({…}・dfor・(dict …))を組まず、defclass・defrecord・defwire の欄と Python の class の欄に写像を持たない(値を型だけで渡す層の欄は DOEFF171)。写像を組むのが目的の定義(:post が写像 — JSON の境界で綴る 1 点・または :tags に :spells / :reads を形の名〔json・http・env・schema・records〕で名乗る外の形を綴る・読む 1 点 — core の外だけ)と、中を読まない中継の型 OpaqueJson の欄は数えない(臭い・数えるだけ)
  Fix:  データを引く写像はキー → 値の関数か効果(例 (ReadRow table key))にし、cache が要るなら handler の session に置く — 欄の写像は欄の名前と型を持つ defrecord にする。JSON を組む綴りは :post が写像の 1 点の定義に寄せる

"""handle / defhandler を使う .hy を実行時の展開と型検査のための展開で展開し、結果の Python を out の dir に書く(直す前後の比べ)。"""

import ast
import pathlib
import subprocess
import sys
import types

import doeff_hy  # noqa: F401
import hy
from doeff_hy.static_view import static_view

root = pathlib.Path(sys.argv[1])
out = pathlib.Path(sys.argv[2])
shard, shards = int(sys.argv[3]), int(sys.argv[4])
out.mkdir(parents=True, exist_ok=True)
files = subprocess.run(
    ["git", "-C", str(root), "grep", "-l", "-E", r"\(defhandler |\(handle ", "--", "*.hy"],
    capture_output=True, text=True, check=True,
).stdout.split()
ok = 0
for rel in sorted(files)[shard::shards]:
    source = (root / rel).read_text()
    for view in ("runtime", "static"):
        name = "snap_" + rel.replace("/", "_").replace(".", "_").replace("-", "_") + "_" + view
        mod = types.ModuleType(name)
        mod.__file__ = str(root / rel)
        sys.modules[name] = mod
        try:
            if view == "static":
                with static_view():
                    tree = hy.compiler.hy_compile(hy.read_many(source, filename=str(root / rel)), mod, filename=str(root / rel))
            else:
                tree = hy.compiler.hy_compile(hy.read_many(source, filename=str(root / rel)), mod, filename=str(root / rel))
            text = ast.unparse(tree)
            ok += 1
        except BaseException as error:  # noqa: BLE001
            text = f"ERROR {type(error).__name__}: {str(error)[:300]}"
        (out / (rel.replace("/", "__") + "." + view + ".py")).write_text(text)
print(f"shard={shard} files={len(sorted(files)[shard::shards])} ok={ok}")

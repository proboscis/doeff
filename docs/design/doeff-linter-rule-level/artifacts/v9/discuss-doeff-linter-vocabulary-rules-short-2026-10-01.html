使わないと決めた言葉の検査 — 残り 161 件の片づけ方

短い版・2026-10-01・確認用(9 月 30 日の長い報告を 1 ページにまとめた物)

何の話か

agora-controllers という repo には、使わないと決めた言葉や呼び出しを code の中から機械で見つける検査(doeff-linter の規則)があります。いまこの検査で「重大(critical)」と出ている物が 161 件残っています。内訳は、mail / letter を code の中の名前に使っている物が 153 件、担当の名前 agora-kanban-dialogue を文字列で直に書いている物が 2 件、時計の呼び出し time.time が 6 件です。9 月 30 日の夜に「mail / letter を code の中の名前に使わない決めは正しい・重大のまま」と決めていただきました。

確認してほしい事: 下の「決めた事」の表の 4 行は、推奨どおりに採って既に進めています(どれも元に戻せます)。「推奨どおりでよい」か「この行が違う」かを教えてください。

161 件はどう片づくか

件数中身片づけ方
148 件本当に直す物 code とテストの中の変数・引数・型の欄・補助関数の名前に mail / letter を使っている(146 件)。担当の名前を文字列で直に書いている(2 件)。 名前を Message 系に変える(例: letter → message-fact)。2 件は定数に置き換える。検査は変えない。別の担当が作業中。
7 件変えられない名前 外部との約束(契約の JSON)で決まっている名前。ACP との契約の欄 carrier.mail(2 件)と、記録の service・画面との通信で使う種類の値 "mail"(5 件)。 相手と共有している名前なので、こちらだけでは変えられない。検査が契約の JSON を読み、そこに在る名前ちょうどの所を数えなければ消える。
6 件時計 検証用の模擬環境から本物の画面へ実際の socket で繋ぐテスト用の部品が、time.time で壁時計を読んでいる。 この部品は、生の入出力を禁じる別の検査の設定で「外の世界に触れてよい部品(時計を含む)」として登録済み。時計の検査もこの登録を読み、部品の中だけ数えなければ消える。

契約の件を直すと、今は「特定の文字列を含む行は丸ごと数えない」という除外で隠れている変数 letter が 6 か所見えるようになります。これも名前の変更で片づくので、直す物は合計 154 件です。

決めた事と、覆すならここ

決めた事理由覆す時の別の案戻し方
契約の欄名の件 — 検査が契約の JSON を読み、そこに在る名前ちょうどの所は数えない。変数・引数・内部の欄は今どおり数える。 数えない理由が「契約に書いてあるか」になる。今の「特定の文字列を含む行を丸ごと除外」は同じ行の内部の名前まで隠し(6 か所)、改行や並びを変えると黙って効かなくなる。doeff-linter(Rust)の変更で 4〜6 時間。 除外する文字列を 4〜5 個足す(10 分・隠れる問題は残る)。型の定義に内部の名前と外部の名前を分けて書く(1〜2 日・実行時の変換に触るので危険)。 契約の JSON の指定を消し、除外の文字列を戻す。
時計の件 — 時計の検査が「外の世界に触れてよい部品」の登録を読み、その部品の中だけ time.time を数えない。 今は同じ部品に「時計に触ってよい」と「time.time を呼ばない」の 2 つの設定が逆のことを言い、検査ごとに片方しか読まない。この形なら登録が 1 か所になり、模擬環境のほかの code の time.time は今どおり見張られる。Rust の変更で 2〜3 時間。 禁止一覧から time.time を外す(30 分)— 生の入出力の検査は模擬環境の code を見ないので、そこの time.time が見張られなくなる。部品を doeff の時計の effect で読む(1〜2 時間・設定の食い違いは残る)。 git revert
テストの file も直す — 検査の対象のまま名前を変える(74 件・作業中)。 「テストの補助関数でも使わない」「除外・既知の一覧・重大さの引き下げで通さない」は決め済み。対象から外すと、テストに mail / letter が戻っても気づけない。 テストを対象から外す(5 分)。テストだけ重大さを下げる(2〜3 時間)。どちらも 9 月 30 日の決めと食い違う。 git revert
ついでに 3 つ
  • 検査の助言文を直す
  • .py / .pyi も対象に足す
  • 複合語は今は数えない
  • 助言文: まだ「直せない物は既知の一覧に載せる」と勧めている(一覧は廃止済み)。
  • .py: 型の欄 mail は .py に在り、今の検査は読まない。.hy だけ直すと実行時に TypeError。
  • 複合語: letters・mail-row など約 1,000 か所。0 件の後に、どこまで改名するかを改めて確認します。
 それぞれ、しない。複合語は今すぐ数える。 それぞれ 1 か所を戻す。

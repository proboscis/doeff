# 悩み別の記事をメイン記事から案内する

- 決定日時：2026-09-15（JST）
- 決定担当：Codex、この会話の執筆担当（personal profile）
- 根拠：ユーザーの指示。メイン記事から悩みの切り口ごとに個別記事へ案内し、各記事で問題と解き方を示し、原稿をリポジトリの著作物として置く。

## 決定と理由

原稿を `publications/zenn-use-cases-v0/` に置く。既存の `publications/zenn-v0/` は章順に読む本であり、今回は困りごとから読む独立記事シリーズなので別に管理する。

メイン記事は、具体的な悩み・doeffでの短い解き方・詳細へのリンクで構成する。機能を列挙するだけでは自分の問題との関係が見えず、全説明を一記事へ入れると入口が重くなるため。

原稿の正本はリポジトリ内のMarkdownとし、プレビューはそこから生成する。公開はまだ行わない。

## 戻す手順

記事の分割を見直す場合は各原稿を統合し、メイン記事と `publications/README.md` の案内を更新する。追加したシリーズを取りやめる場合は、本変更の対象だけをgitで戻す。既存のZenn本や他者の変更には触れない。

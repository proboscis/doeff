# agentd に効く path の名簿
#
# 「この repo の着地が、走っている agentd の中身を変えるか」の**定義点はこの file 1 つ**。
# 何が agentd に効くかを知っているのは doeff なので、名簿の持ち主も doeff。読み手は
# 値を読むだけで、判定の code は repo をまたいで共有しない。
#
# ── 誰が読むか(2026-09-19 現在)
#   * agent-control-plane の配備の拍 `deploy/acp-control/image-beat.sh`
#     — k3s の agentd の pool(Deployment agentd-pool)の版を引くかを判じる
#   * Mac 側の agentd の追随 — 同じ問い・別の担い手
#
# ── 何のために読むか
#   image は自分が焼いた doeff の版を label `io.acp.doeff-revision` で名乗る。読み手はその版と
#   「引く先の image が焼いた版」を **この名簿の path に限って** git で比べ、差が在る拍だけ版を引く。
#   指紋や hash をどこにも置かない —— 2 版の差は git の事実ちょうど(第 2 の場所で計算しない)。
#   読み手はこの file を **本線の先端の写しから** 読む(image の中からではない)。image から読むと、
#   この file が着地する前の image を載せた pool が永久に「読めない」で詰む。
#
# ── 読み方
#   1 行 1 つの git の pathspec(repo の根からの相対)。`#` で始まる行と空行は註。
#   読み手は `git diff --quiet <版 a> <版 b> -- <この名簿>` の 3 値(同じ / 違う / 読めない)で判じる。
#
# ── 変える時
#   ここを 1 行変えれば読み手は全部そろって変わる(読み手の側に写しを置かない)。
#   広げすぎると agentd が要らない入れ替えで落ち、狭めすぎると古い agentd が黙って残る。
#
# ── 初期値の根拠(実測 2026-09-19・9/12 以降の本線 149 commit が触れた file の内訳)
#   packages 765 / docs 259 / .agents 21 / .sisyphus 12 / contracts.lock 11 / tests 7 /
#   .gitignore 6 / .semgrep.yaml 4 / scripts 2 / README.md 2 / doeff 1 / その他 1 ずつ。
#   docs・notes・specs だけの着地を落とし、venv の中身(uv の workspace の member・根の package・
#   依存の集合・interpreter の版)を捉える。tests / scripts / .agents は image には入るが
#   agentd の実行には載らないので外す。

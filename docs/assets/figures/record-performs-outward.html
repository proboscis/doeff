  1. latest_releases yields a request and pauses. record gets it with k.
  2. record yields the same request again, so it goes on out to github.
  3. github counts it as sent and answers with the body, back to record.
  4. record keeps the pair: the method and URL as the key, the body as the answer.
  5. record resumes k with the same body. That k is now used.
  6. The second request goes the same way: two rows in the tape, sent: 2.
  7. The headers, and the token in them, are left out of the key.

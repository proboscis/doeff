  1. yield greet() runs the child as part of twice, like await greet_async().
  2. greet pauses at yield ReadName(). The rest of greet is now a value: k.
  3. The nearest handler of ReadName is titled, so it receives the effect and k.
  4. titled performs the effect again. It goes on out, to ada.
  5. ada answers "Ada" to titled, the code that asked it. greet is still waiting.
  6. titled resumes k with Dr. in front. greet returns "Hello, Dr. Ada".
  7. This call alone runs with grace around it, so its ReadName stops at grace and never reaches titled.
  8. grace resumes k with "Grace", and twice returns. Each handler's Resume returns what the rest of the program returned: grace's first, then titled's and ada's: ('Hello, Dr. Ada', 'Hello, Grace').
  9. Take titled out, and the first greeting is plain Ada: ('Hello, Ada', 'Hello, Grace'). greet is the same function in every run.

def sma_cross(fast: int, slow: int):
closes: list[float] = []
position = 0
cash = 0.0
while (bar := (yield Tick())) is not None:
closes.append(bar.close)
if len(closes) < slow:
continue
f = sum(closes[-fast:]) / fast
s = sum(closes[-slow:]) / slow
if f > s and position == 0:
price = yield Order("buy", 1)
position, cash = 1, cash - price
yield Log(f"t={bar.t} buy {price:.2f}")
elif f < s and position == 1:
price = yield Order("sell", 1)
position, cash = 0, cash + price
yield Log(f"t={bar.t} sell {price:.2f}")
if position:
cash += yield Order("sell", 1)
return round(cash, 2)

  2. paper yields the same Tick again, so it goes on out to recorded.

  4. paper writes down the close. It needs it to fill an Order later.
  5. paper resumes the strategy's k with the bar. That k is now used.
  6. At bar 20 the fast average is above the slow one: Order("buy", 1).
  7. paper answers Order itself, at the last close plus 0.05%: 102.44 × 1.0005. recorded never sees it.

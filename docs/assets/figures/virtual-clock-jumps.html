def virtual_clock(start: datetime):
now = start
sleepers = [] # (wake-up time, order, promise), earliest first
order = count()
advancing = False
@do
def advance(): # idle priority: runs while every other task waits
nonlocal now, advancing
while sleepers:
now, _, promise = heapq.heappop(sleepers)
yield CompletePromise(promise, None)
advancing = False
@handler
def clock(effect: Delay | GetTime, k):
nonlocal advancing
if isinstance(effect, GetTime):
return (yield Resume(k, now))
promise = yield CreatePromise()
heapq.heappush(sleepers, (now + timedelta(seconds=effect.seconds), next(order), promise))
if not advancing:
advancing = True
yield Spawn(advance(), priority=TaskPriority.IDLE, daemon=True)
yield Wait(promise.future)
return (yield Resume(k, None))

  1. bar_clock takes Tick first. Before passing it on, it yields Delay(60) of its own.
  2. No layer in between handles Delay, so it goes out to the clock, with the k of bar_clock.
  3. The clock creates a promise and puts it on the heap, to wake at 09:01.
  4. No advance task runs yet, so the clock spawns one at idle priority.
  5. Wait parks the strategy's task in the scheduler, together with its k.
  6. Every other task waits, so advance runs. It pops 09:01, sets the time and completes the promise.
  7. The task wakes first. The clock resumes its k, and bar_clock passes the Tick on to the feed.
  8. The next Tick puts 09:02 on the heap. advance is still running, so no new task starts.
  9. stamped yields GetTime while it handles Log. The clock says 09:21.
  10. The last Tick waits its minute too and gets None. Five hours and a minute of market time pass in well under a second.

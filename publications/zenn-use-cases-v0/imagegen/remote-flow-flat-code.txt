Use case: infographic-diagram. 日本語技術記事の完成ダイアグラム。添付は表現トーンの参考のみ。全面が不透明な白、ネイビーの日本語、ティールの明瞭な矢印、薄い青/ミント/紫の平面的な角丸枠。写実・3D・金属・ガラス・立体的装置・台座・装飾的なイラストを禁止。横長3:2。図中に下記の短いコードを大きく正確な等幅文字で配置し、対応する操作や流れと矢印で結ぶ。大きいタイトル、余白、最大6ノード程度。日本語の説明を短く、コードは改変しない。原稿からの抜粋なので小さく「コードは抜粋。完全な例は本文へ」。以下の意味を守り、勝手な挙動や架空のAPIを追加しない。
コードは提供されたもののみ。コード各行の日本語コメントも省略せず表示。機械的な循環矢印や図にないAPIを追加しない。
見出し:Programを保存して渡し、実行結果を受け取る
コード:
payload = default_serializer.dumps(calculate())  # 未実行Programを保存
restored = default_serializer.loads(payload)  # Programを復元
assert run(restored) == 6  # 復元後に実行すると6になる
図:白背景の平面図。図の上に3行のコメント付きコードを正確に掲示し『このコードで確認するのは同じプロセスでの往復』と短く注記。下段は本番ハンドラの構成を左から右へ6ノード以内で描く: 『DockerRunを依頼』→『Programを保存』→『コンテナ側で復元』→『run(program)で計算』→『結果を保存・読み戻す』→『結果で続きを再開』。コンテナ側の範囲だけ平らな点線枠で囲む。保存から復元への矢印に『シリアライズしたProgram』、結果から再開への矢印に『この例では6』。大きく『本番構成の説明。実コンテナでの往復は未実行』と注記。実行中の継続の保存、ハンドラの自動移送、上位ファクトリの動作保証を描かない。写真・3D・立体コンテナ・金属を禁止。
説明:本番ハンドラの実装はProgramをシリアライズしてランナーへ渡し、結果を復元して続きを再開します。この記事ではシリアライズの往復を同じプロセスで確認し、実コンテナでの往復は実行していません。

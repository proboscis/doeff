コードは提供されたもののみ。コード各行の日本語コメントも省略せず表示。機械的な循環矢印や図にないAPIを追加しない。
見出し:待機の手順はそのまま、時計を選ぶ
コード:
@do  # 待機と時刻取得をProgramにする
def worker(seconds):  # 時計の実装には依存しない
    yield Delay(seconds)  # 選んだ時計で待つ
    return (yield GetTime())  # 再開した日時を返す
図:白背景、紺文字、青緑の矢印、平面的な角丸枠。左に4行コードを表示。コードのDelayとGetTimeから「時間への依頼」へ。右側の大きな枠は「取り付けるハンドラを1つ選ぶ」。3つの独立した選択肢「仮想時間：sim_time_handler」「非同期の実時間：async_time_handler」「同期の実時間：sync_time_handler」を配置。それぞれ短い説明「次の予定へ時計を進める」「現実の待機中に別タスクを進める」「現実の待機中に実行スレッドを止める」。3つを順番に通す矢印にしない。各選択肢から共通の「日時を返して再開」へ向かう矢印。Programを変えずに解釈を選ぶ構造を示す。写真・3D・時計の写実イラスト禁止。
説明:`Delay`と`GetTime`を書く処理本体は共通です。外側に取り付けるハンドラで、実時間の待機か仮想時計の進行かを選びます。

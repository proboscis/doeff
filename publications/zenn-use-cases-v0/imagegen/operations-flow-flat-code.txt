コードは提供されたもののみ。コード各行の日本語コメントも省略せず表示。機械的な循環矢印や図にないAPIを追加しない。
見出し:PR作成の結果を、署名付き通知へつなぐ
コード:
pr = yield propose_change(work_dir)  # PRまたはNoneを受け取る
if pr is None:  # 差分がなければ終了する
    return None  # 鍵の取得と通知へ進まない
key = yield signing_key()  # 署名用のbytesを受け取る
図:白背景の平面図。左に4行のコード。右に上から「stage済みの差分を確認」→分岐「差分あり？」。なしの矢印は小さな終点「Noneを返す」へ。ありの矢印は「commit・push・PR作成」→「秘密情報を取得しbytesへ変換」→「PR URLへHMAC署名」→「URLと署名をNotify」へ進む。なしの経路を鍵取得や通知へ絶対につながない。PRのmergeはこの流れに含めない。通知に鍵そのものを渡す矢印は描かない。コードのprはPR作成結果、keyは署名の入力に対応する。下に小さく「Git・秘密情報・通知はメモリのハンドラで検証」。写真・3D・立体物は使わない。
説明:差分があればPRを作り、署名鍵を取得して、PR URLと署名を通知します。差分なしなら秘密情報の取得と通知へ進みません。

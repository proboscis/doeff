見出し: Askを受け取り、値を渡して挨拶の続きを再開する
コード:
@do  # 挨拶の手順を組み立てる
def greet():  # 名前を受け取って挨拶する
    name = yield Ask("name")  # ここで中断し、花子を受け取る
    return f"こんにちは、{name}さん"  # 再開後に挨拶を返す
図の意味と流れ: 白背景の平面的なシーケンス図。上に見出しとPythonコードパネルを置く。下に左レーン「greetの本文」、中央レーン「Rust VM」、右レーン「lazy_ask」を並べる。上から下へ時間が流れる。1) greetがyield Ask("name")で中断し、VMへ「Askの依頼」を送る。2) VMがlazy_askへ依頼と続きを渡す。3) lazy_askがenvから「花子」を取り出し、VMへ「花子で再開」と返す。4) VMがgreetへ「name = 花子」を返し、return行へ進む。5) greetが「こんにちは、花子さん」を返し、最下段に「run()の結果：こんにちは、花子さん」を置く。ここで続きを指す小さな注釈は「yieldの後から先」。3D・写実・データベースの立体アイコンを使わず、淡色の箱と方向が明確なティール矢印で示す。
説明: `yield Ask("name")`で本文が中断し、ハンドラが「花子」を渡すと、その値が`name`に入って次の行へ進みます。最後の`return`が、`run()`の結果になります。

コード:
while True:  # collect_openai_streamの中で反復
    chunk = yield Await(anext(iterator, None))  # 1チャンク待つ
    if chunk is None: return text  # 反復終了なら本文を返す
    if chunk.choices:  # 本文の候補がある場合
        text += chunk.choices[0].delta.content or ""  # 断片を追加
図の意味と流れ: 呼び出し「yield collect_openai_stream(stream)」→「次の1チャンクをAwait」→判定「反復が終了した？」。はい→「完成した本文をreturn」→「呼び出し元の続きを再開」。いいえ→「本文の断片を追加」→「次の1チャンクをAwait」へループ。Noneは反復終了の値。下部に「AwaitはSDKとの境界。収集ループは@doの中」と記載。LLMStreamingChatのOpenAI応答を扱う図で、Gemini/OpenRouterのストリームとして描かない。 図内コードはcollect_openai_streamの反復部分の抜粋。iteratorとtextは関数内で初期化済み。
説明: OpenAIのストリームを1チャンクずつAwaitし、反復と本文の収集を@doの中で進めます。

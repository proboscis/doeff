Use case: infographic-diagram. 日本語技術記事の完成ダイアグラム。添付は表現トーンの参考のみ。全面が不透明な白、ネイビーの日本語、ティールの明瞭な矢印、薄い青/ミント/紫の平面的な角丸枠。写実・3D・金属・ガラス・立体的装置・台座・装飾的なイラストを禁止。横長3:2。図中に下記の短いコードを大きく正確な等幅文字で配置し、対応する操作や流れと矢印で結ぶ。大きいタイトル、余白、最大6ノード程度。日本語の説明を短く、コードは改変しない。原稿からの抜粋なので小さく「コードは抜粋。完全な例は本文へ」。以下の意味を守り、勝手な挙動や架空のAPIを追加しない。
コードは提供されたもののみ。コード各行の日本語コメントも省略せず表示。機械的な循環矢印や図にないAPIを追加しない。
見出し: ストリームは、1断片ずつdoeffへ戻す
コード:
chunk = yield Await(anext(iterator, None))  # 次の1断片、終了はNone
if chunk is None:  # 反復の終了を判定
    return text  # 集めた全文を返す
text += chunk  # 到着順に結合
図の意味と流れ: 白背景、平面的なフローチャート。写真、3D、立体装置を使わない。大きな範囲枠を『@do collect_chunksのループ』とし、その内側に『次の1断片を依頼』→『Noneなら終了？』という判断を置く。次の1断片を依頼するノードから外側の『Awaitハンドラとスケジューラ』→『非同期イテレータ』へ矢印、結果chunkが同じ依頼位置へ戻ってから判断へ進む矢印。判断の『いいえ』は『textに断片を結合』→次の1断片を依頼するノードへ戻る。『はい』は『return text』→呼び出し元『yield collect_chunks(stream)』が全文を受け取る流れ。None以外は空文字列でも継続することを小さく補足。コードパネルは『collect_chunksのwhile True内』という見出しを必ず付けた4行抜粋。確認値は『4断片＋終了確認＝Await 5回』。収集ループ全体が非同期イテレータ側で動く図にしない。
説明: 収集ループと結合処理は@doに残し、次の1要素を待つ操作だけをAwaitで非同期実装へ接続します。
図内にResumeのコードを書く場合は正確に Resume(k, "花子") と引用符を付ける。

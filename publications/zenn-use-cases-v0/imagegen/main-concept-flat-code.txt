日本語技術記事の図解。参照画像はトーンだけを使用。完全に不透明な白背景、濃紺の文字、ティールの矢印、薄い青・緑・紫の角丸枠。平面のダイアグラム。3D・写実・金属・ガラス・装置・立体装飾なし。横長3:2。
見出し「操作は同じ、解釈はハンドラ次第」
左の大きなコード枠「処理を書く」に以下を等幅フォントで正確に表示:
@do
def greet():
    name = yield Ask("name")
    return f"こんにちは、{name}さん"
中央の枠「エフェクト」にコード Ask("name") と日本語「名前が欲しい」。
左のyield行から中央へ矢印「依頼」。
右に縦並びの2枠。上「設定から供給するハンドラ」コード {"name": "花子"}。下「テスト用のハンドラ」コード {"name": "テスト"}。
中央から右の2枠へ選択の矢印、2枠上部に「使うハンドラを選ぶ」。
右上枠から下の結果枠へ矢印「この例では花子を返す」。結果枠には name = "花子" と書く。結果枠から左のコードのreturn行へ戻る矢印「値を受け取り、続きへ」。
最下部「同じ処理に、値の供給方法を外側から取り付ける」
2つのハンドラを並行に実行する意味にしない。コードを最大限読みやすく大きく。説明を勝手に追加しない。

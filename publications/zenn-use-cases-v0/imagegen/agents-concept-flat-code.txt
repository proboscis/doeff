Use case: infographic-diagram. 日本語技術記事の完成ダイアグラム。添付は表現トーンの参考のみ。全面が不透明な白、ネイビーの日本語、ティールの明瞭な矢印、薄い青/ミント/紫の平面的な角丸枠。写実・3D・金属・ガラス・立体的装置・台座・装飾的なイラストを禁止。横長3:2。図中に下記の短いコードを大きく正確な等幅文字で配置し、対応する操作や流れと矢印で結ぶ。大きいタイトル、余白、最大6ノード程度。日本語の説明を短く、コードは改変しない。原稿からの抜粋なので小さく「コードは抜粋。完全な例は本文へ」。以下の意味を守り、勝手な挙動や架空のAPIを追加しない。
コードは提供されたもののみ。コード各行の日本語コメントも省略せず表示。機械的な循環矢印や図にないAPIを追加しない。
見出し: エージェントの操作を、ハンドラで解釈する
コード:
session = yield LaunchSession(spec)  # セッションを取得
outcome = yield AwaitResult(session)  # 状態と結果を待つ
yield ReleaseSession(session)  # 利用した資源を解放
return outcome  # 成否の判断材料を返す
図の意味と流れ: 白背景、平面の説明図。左に『共通の@do処理』と4行コード。中央に『選んだハンドラ』。そこから上下2つの選択肢を描く。上は『本番』『実セッションへ接続』、下は『シナリオ』『用意した応答を返す』。両選択肢から右の『AwaitOutcome』『status / result / validation_error』へ矢印。同時実行の分岐に見せず『実行時にどちらかを設置』を付記。コード右の1行目を取得、2行目を状態と結果、3行目を解放へ対応付ける。写真、立体機械、3D、床、質感は使わない。結果を成功と断定せず、状態確認が必要なことを示す。
説明: LaunchSessionとAwaitResultの列は共通です。選んだハンドラが、実セッションまたはシナリオの応答として解釈します。

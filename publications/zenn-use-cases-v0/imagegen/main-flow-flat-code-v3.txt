Title exactly: Askを受け取り、値を渡して挨拶の続きを再開する

白背景の平面シーケンス図。左レーンgreetの本文、中央Rust VM、右handle_ask_effect。1 Ask(name)をVMへ。2 VMが依頼effectと続きkをハンドラへ。3 ハンドラのyield Resume(k, 花子)をVMへ。4 VMがgreetへ花子を渡して再開、nameに花子が入る。5 greetの挨拶が最終runの結果になる。見出しの下にwith_handlers([handle_ask_effect], greet())という設置コードをコメント付きで表示。handler(program)、lazy_ask、envは描かない。kはyieldの後から先の続きという説明を添える。

コード（flowではそれぞれ対応するレーンに配置）：
name = yield Ask("name")  # 依頼して中断
return (yield Resume(k, "花子"))  # 花子で続きを再開

Layout: 上に見出しと設置コード、その下は左右3レーンのシーケンス図。縦方向に時が進む。ハンドラの定義ラベルには「@handler」「@do」「def handle_ask_effect(effect, k):」を表示して、本文に同名の定義があることを示す。継続kの説明は「中断した処理の続き」。右から左へ戻る矢印は必ずResume→VM→greetの順。最後の結果を下に大きく表示する。
上の設置コード:
with_handlers([handle_ask_effect], greet())  # ハンドラを設置

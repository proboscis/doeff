@do  # 待機と結果を、呼び出し元がyieldできるProgramにする。
def worker(seconds: float):  # 必要な待機時間を受け取り、待ち方はハンドラへ委ねる。
    yield Delay(seconds)  # 指定した秒数の経過を依頼し、完了すると次の行へ進む。
    return "完了"  # 待機が終わった後に、呼び出し元へ文字列を返す。
図:白背景の平面シーケンス図。上にコメント付き4行コード。下の列は左から「workflow」「worker」「選んだ時間ハンドラ」。上から下へ時系列で、workflowからworkerへ「子Programをyield」、workerから時間ハンドラへ「Delay(seconds)」、ハンドラの待機処理「同期・非同期・仮想時間のいずれか」を示す平たい枠、ハンドラからworkerへ「Noneを渡して再開」、workerからworkflowへ「完了を返す」。最後にworkflow列に「処理結果: 完了」。Delayが「完了」を返すのではなく、DelayはNoneで再開しworkerのreturnが文字列を返すことを厳守。3つの時計を並列に動かす図にしない。写真・3D不可。
